# hyrox-data (private)

Training data for the Sub-60 Race Hub (https://cjgoodrow.github.io/hyrox-hub/).

- `data.json` is written by the hub (Settings → Sync with GitHub). Don't edit it by hand while the hub is open on a device; reload the hub after any manual change.
- The data shape is documented in the hyrox-hub README.
- Claude reads this repo to review strength blocks and writes reviews back into `blocks[].review`.
